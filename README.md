# Exercise 5 - Python Tasks

This repository contains two Python scripts that demonstrates dictionary creation, find keys in dictionary,creating list, slicing list, reversing list.

## Task 1: Create a Dictionary of Student Marks
.
**File:** `Task1.py`

### Description
 - This script create a dictionary.
 - finds entered keys and values in dictionary.

### How to Run
1. Open a terminal or command prompt.
2. Navigate to the directory containing `Task1.py`.
3. Run the script using the command:
   ```
   python Task1.py
   ```
4. Enter name, code will display marks if person found in dictionary. else it will say student not found.
